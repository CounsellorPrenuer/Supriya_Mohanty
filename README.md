# Supriya Mohanty - LeapMentor Website

Production website code for LeapMentor.

## Branch and Root
- Branch: `main`
- Folder: repository root (`/`)

## Tech
- Next.js (App Router)
- Sanity Content API (content-managed sections)

## Sections
- Home
- About Founder
- Services
- Packages
- Testimonials
- Contact Us

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```

## Notes
- This repository contains static/frontend code in root.
- Sanity Studio/schema files are intentionally not included here.
- Content changes in Sanity reflect on the site through API fetches.
